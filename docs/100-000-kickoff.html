Tips & Tricks

  • Context is king. Prompts are the queen
  • Use rules/system-prompts (claude.md, claude.local.md, ~/.claude)
  • Build (context), Plan, Do, Evaluate (!), Iterate, …
  • Use MCP-Servers to add tools, resources, prompts, …

Anti-Patterns

  • Generate documentation
  • Generate implementation AND the tests
  • (Non-selective) YOLO (trust, but verify; HIL)
  • Using AI for coding only (20% of everything vs. 80% of coding)
